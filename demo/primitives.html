API reference

Drawing

Start with simple geometry

Draw circles, rectangles, lines, and curves with chainable canvas methods.

Arc

Draw a section of a circle between two angles.

Bézier

Use two control points to bend a cubic Bézier curve.

Circle

Position a circle by its center and radius.

Curve

Join segments with a tangent arc.

Ellipse

Draw an ellipse using its full width and height.

Line

Connect two points with the current stroke.

point

Use the stroke width to set the diameter of a point.

Quad

Connect four vertices to form a quadrilateral.

Rect

Set the position, width, and height of a rectangle.

Square

Use one size for both dimensions of a square.

Triangle

Connect three vertices to create a filled triangle.

Try it yourself

Compare the examples, then open the example source to change the coordinates and styles.

Canvas coordinates

Coordinates use canvas units and angles use radians. On smaller screens, scroll within a canvas panel to see the full drawing.
