Drawing reference

Six building blocks used throughout the application examples. Adapt a recipe, then see it in context in one of the demos.

Primitives

Combine familiar geometry with fills and strokes.

Combine familiar geometry with fills and strokes. 
context.fill('#2563eb').noStroke()
    .circle(80, 110, 42)
    .rect(155, 68, 100, 84)
    .noFill().stroke('#0d9488').strokeWidth(4)
    .triangle(250, 160, 295, 65, 335, 160);

Gradients and text

Use a gradient as a fill, then place a text label.

Use a gradient as a fill, then place a text label. 
const gradient = context.linearGradient(30, 0, 330, 0);

gradient.addColorStop(0, '#2563eb');
gradient.addColorStop(1, '#0d9488');
context.fill(gradient).noStroke().rect(30, 40, 300, 140)
    .fill('#fff').font('sans-serif').fontSize(32)
    .fontWeight('bold').textAlign('center')
    .textBaseline('middle').text('Hello, canvas.', 180, 110);

Saved transforms

Isolate each transform with push() and pop().

Isolate each transform with push() and pop(). 
context.noFill().stroke('#94a3b8').strokeWidth(2)
    .rect(120, 75, 120, 70)
    .push().translate(180, 110).rotate(Math.PI / 5)
    .noStroke().fill('#2563eb').rect(-60, -35, 120, 70)
    .pop();

Reusable paths

Build geometry once and draw it with different styles.

Build geometry once and draw it with different styles. 
const path = context.createPath()
    .vertex(35, 150)
    .bezierVertex(100, 0, 240, 220, 325, 70);

context.noFill().stroke('#2563eb')
    .strokeWidth(5).drawPath(path)
    .noStroke().fill('#0d9488')
    .circle(35, 150, 7).circle(325, 70, 7);

Layers and contours

Subtract an inner contour from a filled shape.

Subtract an inner contour from a filled shape. 
const ring = context.createShape(180, 110)
    .layer((path) => path.circle(0, 0, 72))
    .contour((path) => path.circle(0, 0, 36));

context.fill('#0d9488').noStroke().drawShape(ring);
