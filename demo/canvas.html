API reference

Drawing

Control the drawing surface

Clear pixels, save drawing state, and transform the coordinate system.

Background

Fill the entire drawing surface.

Clear

Remove all pixels. The checkerboard shows the now-transparent canvas.

Erase

Cut a transparent rectangle out of the background.

Resize

Resize the canvas to 100 by 100 units.

Push

Save drawing state before changing styles and transforms.

Pop

Restore saved styles and transforms before drawing.

Reset

Restore default styles and the identity transform.

Translate

Move the drawing origin before drawing the second outline.

Rotate

Compare the original outline with a rotated outline. Angles use radians.

Scale

Scale the X and Y axes independently.

Apply matrix

Compare the original rose outline with a skewed blue outline.

Reset matrix

Remove an applied matrix before drawing.

Try it yourself

Compare the examples, then open the example source to change the coordinates and styles.

Canvas coordinates

Coordinates use canvas units and angles use radians. On smaller screens, scroll within a canvas panel to see the full drawing.
